# Omihirofumi Tap

## How do I install these formulae?

`brew install omihirofumi/tap/<formula>`

Or `brew tap omihirofumi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "omihirofumi/tap"
brew "<formula>"
```

## prpr

Review GitHub pull requests with Jujutsu workspaces, Helix navigation, and inline comments:

```sh
brew install omihirofumi/tap/prpr
```

Run `prpr` inside a repository, or `prpr 123` to open a specific PR. See the [project README](https://github.com/omihirofumi/prpr#readme) for the review controls.
